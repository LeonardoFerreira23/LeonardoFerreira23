### Em destaque

**[BHV Transfer](https://github.com/LeonardoFerreira23/bhv-transfer)** · `Java 21` `Spring Boot 3` `Spring Data JPA` `PostgreSQL` `Docker`
API para recebimento de pacotes de vistoria técnica. Envio em blocos de 10 MB com remontagem no servidor, suporte a arquivos acima de 1 GB e até 3 novas tentativas por bloco em caso de falha de conexão. Lógica de upload coberta por testes com JUnit 5 e Mockito.

**[ConstruAI](https://github.com/LeonardoFerreira23/construai)** · `Next.js` `TypeScript` `Genkit` `Gemini` `Turf.js`
Análise de viabilidade de empreendimentos por zoneamento urbano, com parecer gerado por IA a partir de um ponto no mapa. 1º lugar no Hackathon Construtech 2025.

**[GPS Report Generator](https://github.com/LeonardoFerreira23/gps-report-generator)** · `Java 17` `Spring Boot` `JavaFX` `jpackage`
Aplicação desktop que gera o mapa padronizado de relatórios técnicos de campo a partir de coordenadas, integrando as APIs Static, Geocoding e Elevation do Google Maps. Empacotada como instalador Windows, roda sem Java na máquina do usuário.
